Institutional Data Dictionary, Schema Attributes, and Validation Rules for Accreditation & Analytics

Release 2.4   NBA Tier-II Compliant
Technical Standard Specification
Specification Scope: This document defines every required, computed, and accreditation-linked attribute for student master records in AcademiQ. It serves as the formal schema contract for batch Excel/CSV uploads (Student_Master_Data.xlsx), API data integrations, and database tables supporting Continuous Internal Evaluation (CIE), Attendance, ML Retention Risk Modeling, DPDP parent outreach, and NBA Criteria 4 & 5 reporting.

9. Batch Ingestion Specifications & Excel Standards Supported Formats: .xlsx, .csv, .json

When preparing spreadsheets (e.g., Student_Master_Data.xlsx) for automatic ingestion into AcademiQ, the following rules apply:

Special Symbol Notation in Grade Reports

• 'A': Indicates student was Absent for that test (computed as 0.0 with absent flag recorded).
• 'NE': Indicates Not Eligible / Not Entered (student barred due to attendance deficit).
• 'NA' (Shaded Cells): Student was not enrolled for that elective course or semester report.
• USN Header: Column header must be labeled USN or student_id in row 1 or 2.

Database Normalization & Multi-Report Matching

• Primary Anchor: All disparate reports (Attendance, IA marks, Electives) join cleanly on USN.
• Header Regex: Course code in header must match pattern (CS[0-9][A-Z][0-9]{2}).
• Section Normalization: Automatic mapping to sections A, B, C based on division tags.
• Idempotent Upsert: Re-uploading spreadsheets updates existing marks without duplicate rows.

11. Database Entity-Relationship Mapping Summary PostgreSQL Relational Storage

Core Relational Entities

• students: Primary master table containing USN, demographics, attendance %, internal marks, and courses JSON.
• departments: 1-to-N parent entity for student program enrollment.
• student_enrollments: Term-specific mapping linking student to academic section and timetable rooms.
• parent_contacts: 1-to-1 privacy-protected guardian contact records.

Accreditation & Outcome Entities

• placement_records: Placement offers, packages, and company details.
• student_achievements: Certified student honors, competitions, and prizes.
• event_registrations: Co-curricular RSVP, attendance, and duty leaves.
• academic_batches / progress: Cohort progression for Criteria 4.1 to 4.4.
